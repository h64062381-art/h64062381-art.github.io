KIWI - تحديث نظام المشتريات والجرد والهدر إلى نظام سندات/فواتير متعددة البنود

الملفات المعدلة:
1) purchases-full.html
   - فاتورة مشتريات واحدة تضم عدة مواد.
   - إضافة/حذف/دمج السطور قبل الحفظ.
   - إجمالي الفاتورة، المدفوع، المتبقي.
   - ترحيل كل المواد للمخزون دفعة واحدة.
   - إنشاء حركة مخزون وقيد محاسبي للفواتير.

2) inventory.html
   - الإبقاء على تعريف الأصناف والمخزون.
   - إضافة تبويب "سند جرد متعدد الأصناف".
   - يمكن إضافة أصناف متعددة أو إضافة كل الأصناف الحالية للسند.
   - حفظ سند واحد وترحيل الفروقات للمخزون وحركات المخزون.

3) waste-full.html
   - سند هدر واحد متعدد المواد.
   - لكل مادة كمية وسعر وقيمة وسبب.
   - خصم جميع المواد من المخزون دفعة واحدة.
   - توثيق السند وحركة المخزون.

أضف هذه الملفات مكان الملفات القديمة في نفس مشروع KIWI.
