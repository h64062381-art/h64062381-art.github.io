طريقة التركيب:
1. فك ضغط night-mode-addon.zip.
2. ضع night-mode.js و night-mode.css بجانب ملف index.html الرئيسي في مشروعك.
3. أضف هذا السطر قبل </body> في صفحات المنيو:
<script src="night-mode.js"></script>
4. إذا عندك أكثر من صفحة HTML للمنيو، أضف السطر لكل صفحة.

الإضافة مستقلة ولا تحتاج مكتبات خارجية.
زر ليلي بسيط + حفظ اختيار الزبون في المتصفح.
